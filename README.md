"Allow Once", an original short poem about agency: a coding agent's permission prompt and a daughter's first drives alone, and the night trust stops being a setting. `main.ts` writes it to `/output/entry.txt`, the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
